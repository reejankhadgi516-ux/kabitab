# KABITAB WordPress Studio source

This repository contains the KABITAB-specific WordPress plugin from the active local WordPress Studio site.

## Install

Copy `wp-content/plugins/kabitab-story-system` into the same path of a WordPress installation, then activate **KABITAB Story System** in WordPress Admin.

WordPress core, the Studio SQLite database, uploads, cache, backups, and third-party plugins are deliberately excluded. They are runtime data or third-party dependencies and should not be committed to GitHub.
